# 🧩 Combining Shortcuts

A powerful convention is:

```text
\[style] + [purpose]
```

This creates a consistent personal prompt language.

### Examples

```text
\3dbillboard
```

3D + Billboard

```text
\handwrittennotes
```

Handwritten + Notes

```text
\3dinfographic
```

3D + Infographic

```text
\handwrittenmindmap
```

Handwritten + Mind Map

```text
\comicexplain
```

Comic + Explanation

```text
\3darchitecture
```

3D + Architecture

# 🚀 Suggested Personal Prompt System

Instead of remembering hundreds of commands, use three levels:

```text
STYLE
\3d
\handwritten
\cinematic
\comic
\watercolor
\sketch
\photorealistic

PURPOSE
\billboard
\notes
\infographic
\mindmap
\architecture
\diagram
\thumbnail
\poster

EXPLANATION
\explain
\eli5
\study
\revision
\cheatsheet
```

Then combine them conceptually:

```text
\3d + billboard
\handwritten + notes
\handwritten + mindmap
\3d + architecture
\cinematic + poster
\comic + explain
\photorealistic + product
```

This gives you a scalable **personal AI visual prompt language** that can grow without becoming difficult to remember.
